Part 1: Minimum Distance Optimization

Part 1 investigates methods for determining the minimum distance between a given point and a nonlinear function. A point on the function can be represented as (x, f(x)), allowing the Euclidean distance between the curve and the given point to be written as an objective function.

Three methods are compared: an analytical solution, Newton-Raphson, and golden-section search. Each method is used to determine the point on the function that minimizes this distance and to calculate the corresponding minimum distance.

1. Analytical Method

The analytical method finds the minimum by differentiating the objective function and solving for its stationary points. This gives a reference solution that can be used to verify the numerical methods.

General Procedure

  1. Represent a general point on the function as (x, f(x)).
  2. Use the Euclidean distance formula between the point (x, f(x)) and the given point (xp, yp):

    d(x) = √[(x - xp)² + (f(x) - yp)²]
  3. To simplify the optimization, minimize the squared distance instead:

    D(x) = (x - xp)² + (f(x) - yp)²
  4. Differentiate the squared-distance function to obtain D'(x).
  5. Set D'(x) = 0 and solve for the stationary point(s).
  6. Evaluate D''(x) or compare the candidate distances to confirm which stationary point gives the minimum distance.
  7. Substitute the minimizing x-value into f(x) to obtain the closest point on the curve.
  8. Calculate the final minimum distance using the distance formula.

2. Newton-Raphson Method

Newton-Raphson was used as a numerical method for finding the value of x that minimizes the distance between the given point and the function. The same squared-distance objective function from the analytical method is used, but instead of solving its derivative directly, Newton-Raphson iteratively searches for a root of D'(x).

xn+1 = xn - D'(xn) / D''(xn)

General Procedure

  1. Define the squared-distance objective function: D(x) = (x - xp)² + (f(x) - yp)².
  2. Calculate the first and second derivatives, D'(x) and D''(x).
  3. Select an initial guess x0.
  4. Evaluate D'(xn) and D''(xn).
  5. Use the Newton-Raphson update equation to calculate the next estimate xn+1.
  6. Repeat until the change between successive estimates is below the selected tolerance.
  7. Use the converged x-value to determine the closest point (x, f(x)) on the function.
  8. Calculate the minimum distance between this point and the given external point.

3. Golden-Section Search

Golden-section search was also used to determine the minimum distance between the given point and the function. Unlike Newton-Raphson, golden-section search does not require derivatives. Instead, it directly compares values of the distance objective over a search interval and progressively narrows the interval containing the minimum.

General Procedure

  1. Define the squared-distance objective function: D(x) = (x - xp)² + (f(x) - yp)².
  2. Select an initial interval [a, b] that is expected to contain the x-value corresponding to the minimum distance.
  3. Calculate two interior points using the golden-section ratio.
  4. Evaluate the distance objective D(x) at both interior points.
  5. Compare the two distances and discard the portion of the interval that cannot contain the minimum.
  6. Repeat the interval reduction until the search interval becomes sufficiently small.
  7. Estimate the x-value corresponding to the minimum distance.
  8. Substitute this value into f(x) to obtain the closest point on the curve and calculate the final minimum distance.
